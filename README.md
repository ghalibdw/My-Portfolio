## Technical Highlights & Architecture

- **Single-Page Architecture (SPA):** Seamless single-DOM structure consolidating all academic, athletic, project, and career records into a smooth-scrolling experience with sticky glassmorphic navigation and active scroll-spy tracking.
- **Spatial 3-Card Carousel (`FLOU | CLAIR | FLOU`):** A custom horizontal carousel maintaining three projects simultaneously in viewport:
  - **Center Card (`CLAIR`):** High-focus spotlight, full scale, sharp rendering, and interactive buttons.
  - **Peripheral Cards (`FLOU`):** Scaled-down depth position with isolated blur on media while keeping titles razor-sharp.
  - **Physics & Controls:** 4-second autoplay with pause-on-hover, touch/swipe acceleration for mobile, and left/right keyboard navigation.
- **Deep-Dive Case Study Modals:** In-depth technical architecture overviews for each engineering system.
- **Printable Executive Resume (@media print):** Built-in one-page printable CV sheet accessible via modal with dedicated print CSS.
- **Domain-Grouped Skills Matrix:** Categorized competencies across Systems OOP, Frontend/Full-Stack, Quantitative Sciences, and Spoken Languages without arbitrary percentage bars.
- **Direct Communication:** Real-time form validation dispatching to `mailto:ghalibadawi08@gmail.com` plus direct WhatsApp integration via official click-to-chat.
- **Standards & Accessibility:** Fully WCAG 2.1 AA contrast compliant, keyboard navigable, responsive down to 320px screens, reduced-motion friendly, and enriched with Open Graph cards and JSON-LD Person schema.

## Deployment

Deployable as a zero-dependency static site on any platform:

### GitHub Pages
1. Push this repository to GitHub.
2. Navigate to **Settings > Pages**.
3. Under **Branch**, select `main` and `/ (root)`, then click **Save**.

### Vercel / Netlify
1. Connect your GitHub repository to Vercel or Netlify.
2. Set Build Command to empty and Output Directory to `./`.
3. Deploy.
