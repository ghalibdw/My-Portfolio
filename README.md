# Ghali Badawi — Portfolio Website (`ghalibdw`)

## Overview
Redesigned single-page engineering & design portfolio for **Ghali Badawi**, crafted with an Apple / Linear / Stripe / Vercel aesthetic, spatial 3-card project carousel (`FLOU | CLAIR | FLOU`), interactive resume timeline, printable one-page CV export, and WCAG 2.1 AA accessibility.

## Quick Start & Adding Your Portrait Photo
1. Place your portrait photo at `images/ghalibadawi.jpg` (or click **+ Set Photo** directly in the Hero portrait card in your browser).
2. Open `index.html` in any modern browser, or deploy the folder directly to **GitHub Pages**, **Vercel**, or **Netlify**.
